# Release maintenance

- Update `CHANGELOG.md` for every release, based on the changes since the previous tag. Use concise English and describe visible or audible changes; include film timestamps where useful.
- Use that version's changelog entry in the GitHub Release notes, followed by the download's resolution, frame rate, duration, and audio status. Keep both records in sync.
- Keep English as the default README and retain the Chinese version. Preserve the live site and download links.
- Keep rendered videos out of Git. Release downloads use 1080p at 30 fps unless requested otherwise.
