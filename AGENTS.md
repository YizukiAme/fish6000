# Release maintenance

- Update `CHANGELOG.md` and `CHANGELOG.zh-CN.md` for every release, based on the changes since the previous tag. Keep both languages in sync, with English first. Use concise wording and describe visible or audible changes; include film timestamps where useful.
- Use that version's changelog entry in the GitHub Release notes, followed by the download's resolution, frame rate, duration, and audio status. Add the Chinese entry in a collapsible `中文` section after the English notes and download details. Keep the changelogs and Release notes in sync.
- Keep English as the default README and retain the Chinese version. Preserve the live site and download links.
- Keep rendered videos out of Git. Release downloads use 1080p at 30 fps unless requested otherwise.
